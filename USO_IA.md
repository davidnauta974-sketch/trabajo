# Declaración de apoyo mediante inteligencia artificial

Se utilizó Codex de OpenAI como apoyo para redactar y revisar políticas Rego,
casos de prueba, una aplicación mínima de laboratorio en Go, configuraciones
Docker y GitLab CI/CD y el informe técnico.

La asistencia incluyó consultas a documentación oficial y ejecución de
herramientas locales. Los resultados de Conftest y Go se conservan como
registros de ejecución; no se sustituyen pruebas de GitLab o Docker por salidas
simuladas. El estudiante debe revisar el código, comprender las reglas,
reproducir las pruebas y estar en capacidad de explicar sus decisiones.

La aplicación es una base de laboratorio creada para esta actividad, no una
copia de la plantilla original ni evidencia de actividades de semanas previas.
